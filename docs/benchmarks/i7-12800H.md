# Benchmarks on an Intel Core i7-12800H

Intel Core i7-12800H (Alder Lake, 6 P-cores + 8 E-cores), Windows 11, BenchmarkDotNet 0.16 (medium job),
.NET 8.0.31 and .NET 10.0.12, Snappier 1.3.1 as the baseline. One process per file, run one after another, each
pinned to a single P-core (`scripts/bench-local.ps1`). Speedup is Snappier time / Snappiest time, as the median of
three runs for net8.0 and four runs for net10.0.

Pinning matters on this CPU: a thread that lands on an E-core runs Snappier compression about 3.5x slower than on a
P-core. Snappier's timings also vary more between runs here than on the AMD EPYC 7543 host used for the main
tables, so a few ratios move more. Results on the EPYC host: [README.md](README.md).
